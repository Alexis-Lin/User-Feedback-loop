## 语言
7 种：`zh` 简体中文 · `en` English · `ja` 日本語 · `es` Español · `pt` Português(BR) · `de` Deutsch · `fr` Français。
真机**跟随系统语言**；原型 / PRD 里的语言开关仅供评审对照。

## 本版要点（相对旧 Bug Report）
1. **抽屉式**：一级列表选类型 → 底部抽屉填内容，填完即走，不做整页二级跳转。
2. **5 分类 MECE**：AI 识别准确性 / 课程内容（含新增动作申请）/ 连接数据与使用体验 / 其他问题 / 新功能建议。
3. **复用既有链路**：AI 识别、课程内容的选项与"课中报错"逐条一致，直接进现有看板 / bug bot；新功能建议进产品需求池。
4. **降阻力**：截图折叠成一行（点 + 展开）；补充说明可打字 / 语音；空值校验防无效提交。
5. **联系方式成组卡片**：国际=邮箱预填、大陆=手机号预填+补充邮箱+企业微信；底部默认勾选「有需要才找你，平时不打扰」。
6. **7 语言**。

## 给工程的接入顺序
1. 读 **PRD**（分类 / 校验 / 路由 / 归并）。
2. 跑 **flutter/**（`FeedbackEntryPage` 直接可看 UI；录音 / 截图 / 上传按 README TODO 接真机）。
3. 文案接 **i18n.json**（转 ARB）；契约按 PRD §6 的 payload 先定，再前后端并行。
